# favze-portal
Favze Digital Marketing's Client Portal.

Every section is its own page (`portal-dashboard.html`, `portal-billing.html`, `portal-tickets.html`, and so on). All pages share `portal-styles.css` and `portal-app.js`. `index.html` opens the dashboard.

Host the folder as-is on any static host (GitHub Pages works). It shares one Supabase database with the Favze CRM.
